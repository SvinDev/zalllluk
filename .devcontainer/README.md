# УК Онлайн в Codespaces

При запуске Codespace весь стек поднимается автоматически: PostgreSQL, API и веб-интерфейс
(тот же `docker-compose.yml`, что и на сервере). Ход запуска виден в терминале
«Codespaces: postStartCommand»; первый старт с пустой базой занимает несколько минут
(сборка образов), последующие — быстрее.

## Открыть приложение

Вкладка **Ports** → порт **8080 «УК Онлайн»** → значок глобуса. Swagger API — по адресу
`/api/docs` того же порта.

Демо-данные загружаются автоматически, если база пустая. Пароль у всех — `demo12345`:

| Email | Роль |
|---|---|
| admin@demo.ru | администратор |
| manager@demo.ru | управляющий |
| buh@demo.ru | бухгалтер |
| guard@demo.ru | охрана |

По умолчанию порт приватный: открыть ссылку можете только вы (после входа в GitHub).
Чтобы показать кому-то — правый клик по порту → **Port Visibility → Public**. Код
репозитория по этой ссылке не виден, только работающее приложение.

## Данные

База живёт в Docker-томе внутри Codespace и **сохраняется между остановками и
перезапусками**. Удаляется только вместе с Codespace — перед удалением сделайте бэкап.

```bash
make backup                               # дамп в backups/ (в git не попадает)
make restore f=backups/uk-....dump        # восстановить из дампа
make reset-data                           # удалить все данные (спросит подтверждение)
make docker-seed                          # демо-данные в пустую базу
```

Скачать бэкап на компьютер: правый клик по файлу в `backups/` → Download.

## После изменений в коде

```bash
make up      # пересобрать и перезапустить стек
make logs    # логи API и веб-сервера
```

Для разработки с автоперезагрузкой есть `make dev-api` / `make dev-web` (см. корневой README).

Codespace засыпает после периода бездействия — при следующем открытии стек
поднимется сам, данные на месте.
